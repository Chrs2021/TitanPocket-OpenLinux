# OZ8806 fuel gauge

`drivers/power/supply/oz8806_battery.c` — new, clean-room driver.
Config: `CONFIG_BATTERY_OZ8806=y`. Binds to the stock dtbo node
`i2c6/coulomb@2f` (`compatible = "mediatek,coulomb"`).

Exposes a `power_supply` named **`oz8806-battery`** with status, voltage,
current, capacity, charge now/full, design limits and temperature.

## Background

The stock kernel's Agold/O2Micro driver links O2Micro's closed "bmulib" SoC
algorithm and feeds the MediaTek battery framework. Unihertz never released
source. The register map, scaling and battery tables here were recovered from
the stock kernel binary (functions `afe_read_*`, `bmu_*`, `oz8806_*`, and the
`config_data`/OCV/NTC tables in `.data`).

## Registers

All accesses are SMBus word reads/writes (little-endian), retried up to 8
times like the stock code.

| Reg | Name | Conversion |
|---|---|---|
| 0x00 | chip id | byte; reads `0x38` |
| 0x09 | OP_CTRL | bit 6 = sleep. Wake: write `0x20`. Power-down: `0x60` (single cell) |
| 0x0C | NTC voltage | `mV = (raw/16) * 2.5`; `R = mV * Rpullup / (1800 - mV)`; R -> temp via table |
| 0x0E | cell voltage | `mV = (raw/16) * 2.5` (signed) |
| 0x10 | OCV voltage | same scaling as 0x0E |
| 0x12 | current | `mA = raw * 7.8125 / Rsense(10) / 4` (positive = charging) |
| 0x14 | CAR (coulomb counter) | `mAh = raw * 5 / 10`; write `raw = mAh * 2` |
| 0x18 | board offset | current-offset calibration (left as programmed) |

Stock configuration (from `config_data`): Rsense 10 mOhm, CAR LSB 5, current
LSB 7.8125 uV, voltage LSB 2.5 mV, design capacity 4250 mAh, CV 4400 mV,
end-of-charge current 300 mA, discharge end 3450 mV, NTC reference 1800 mV.

## State of charge

The chip's coulomb counter *is* the remaining capacity in mAh (the stock
driver writes it that way), and it is battery-powered, so it carries over
from Android and across reboots.

- **capacity** = CAR / 4250 mAh, clamped 0–100 %.
- **Seeding:** at probe, if CAR is 0 or above design + 5 %, it is seeded from
  the OCV register through the stock 65-point OCV table.
- **Full anchor:** voltage within 50 mV of 4.40 V and charge current below
  300 mA for 3 polls (15 s) -> CAR = 4250.
- **Empty anchor:** below 3.45 V while discharging for 3 polls -> CAR = 0.
- Poll interval 5 s; `power_supply_changed()` each poll.

## Temperature

The NTC pull-up differs between board variants. Stock reads **GPIO 5**:
high -> 24 kOhm, low -> 120 kOhm. We do the same through
`agold_gpio_get_in()` (added to `drivers/pinctrl/mediatek/pinctrl-paris.c`).
A DT property `o2micro,ntc-pullup-ohm` would override it, but the stock dtbo
does not set one. With the wrong pull-up the reading is far off (e.g. −10 °C
instead of 29 °C), which is how the variant was found.

## Relationship to the MediaTek battery driver

MediaTek's own gauge (`battery`, PMIC-based) still loads and still controls
charging. On this board its capacity reads `-1`; voltage and current agree
with ours. Userspace should prefer `oz8806-battery` for percentage. Hiding the
MediaTek supply is a possible follow-up.

## Verifying

```sh
cat /sys/class/power_supply/oz8806-battery/{capacity,voltage_now,current_now,temp}
dmesg | grep oz8806
```
